# ☕ JavaTalk

JavaTalk is a desktop AI chatbot developed using Java Swing. The application allows users to chat with an AI assistant through a simple and clean interface. It was built as a personal project to improve my Java programming skills and gain hands-on experience with APIs, GUI development, and Maven.

## Features

- Chat with an AI assistant using the OpenRouter API
- Clean and user-friendly Java Swing interface
- Save chat conversations as a text file
- Message timestamps
- Menu bar with useful options
- Responsive UI using SwingWorker
- Built using Java and Maven

## Technologies Used

- Java 23
- Java Swing
- Maven
- Jackson
- OpenRouter API
- IntelliJ IDEA

## How to Run

1. Clone the repository.

```bash
git clone https://github.com/aryansaha210-ops/JavaTalk.git
```

2. Open the project in IntelliJ IDEA.

3. Install the Maven dependencies.

4. Add your own OpenRouter API key in the project (or configure it as an environment variable).

5. Run `Main.java`.
